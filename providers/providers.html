      How rules work
      Disabled tools are hidden from the agent and blocked at execution. Local access and controller authorization must still be enabled. Tools are not a sandbox: an allowed command can perform file operations even when a file tool is disabled.
      
      
      Reset tool permissions?
      Remove all group defaults and individual overrides.
