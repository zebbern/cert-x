## Run contract

The live harness loads `OPENROUTER_API_KEY` from this checkout's `.env.local` inside the local Node process. The browser stores a placeholder key and sends model requests to a localhost proxy. That proxy fixes the upstream model to the user-selected `xiaomi/mimo-v2.6-flash`, passes the chat's advertised tool schemas and IDs, and enforces at most 24 inference requests, 1,200 output tokens per request, ten minutes from the live prompt, and a $0.50 conservative accounted-cost ceiling. Pricing is read from the provider catalog before dispatch. `CERT_X_LIVE_PRIOR_COST_USD` carries prior attempted-run spending into that ceiling. It records provider HTTP status, usage, generated tool calls, returned tool results, and terminal state under `%LOCALAPPDATA%/cert-x/verification/`. The selected model is paid; no model fallback is configured. Earlier runs used the now-retired free MiniMax variant.

The harness first uses two scripted tool calls in the same chat to prepare a **real** DAST/SAST scan from traffic captured by the extension on a resettable localhost fixture. The live model receives the resulting scan ID and must select its own investigation tool calls. The fixture has no external targets or real accounts. The native host registration is installed only after checking Chromium has no existing registration, and the harness deletes only its own registration, daemon, browser profile, and work directory.

Run from the repository root:

```powershell
node tools/security/tests/live-model.browser.cjs
node tools/security/tests/live-model-verify.cjs
```

The verifier checks native outcomes in retained tool results and exits nonzero on material failures. A completion message from the assistant alone is insufficient.
